# Playbook Trial

A practice app for testing the new-app setup.

A static web app (plain HTML/CSS/JS, no build step) hosted on GitHub Pages,
released through stages: Dev → Alpha → Staging → Production.

| Stage | Address |
|---|---|
| Dev | https://thedodgykiwi.github.io/playbook-trial/dev/ |
| Alpha | https://thedodgykiwi.github.io/playbook-trial/alpha/ |
| Staging | https://thedodgykiwi.github.io/playbook-trial/staging/ |
| Production | https://thedodgykiwi.github.io/playbook-trial/ |
| Pipeline (what's where) | https://thedodgykiwi.github.io/playbook-trial/pipeline/ |

Set up from the app starter in [app-playbook](https://github.com/Thedodgykiwi/app-playbook),
which also provides the shared deploy and the promote skill.

Run locally: `python3 -m http.server 8080` and open http://localhost:8080.
